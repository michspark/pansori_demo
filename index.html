Frame-Level Pansori Mode Classification with Complementary Audio Representations

Sangheon Park, Seonguk Ju, Suin Chung, Danbinaerin Han, Dasaem Jeong

Paper (coming soon) Code Data & Weights

Overview

A pansori performance moves between musical modes (jo, 조) as the story unfolds, and between sung passages and spoken narration. Our model labels every frame of a recording with the mode being performed, so mode-change boundaries fall out of the frame sequence instead of being predicted directly.

We compare seven input representations under one training pipeline, with identical splits and metrics: waveform-derived (mel spectrogram, CQT, chroma), pitch contours (PESTO, CREPE), symbolic (a transcribed-MIDI piano roll) and self-supervised features (CultureMERT-95M). The representations are complementary, and a weighted soft vote across them works best. The examples below use the Mel + PESTO + MIDI ensemble. Each stream runs at its own frame rate, so all three are pooled onto the slowest (MIDI, 10 fps) before voting.

  • Ujo 우조 Also covers gyeongdeureum, seolleongje and pyeongjo, which are folded into this class.
  • Gyemyeonjo 계면조
  • Aniri 아니리 Spoken narration between sung passages.
  • Changjo 창조

Run it on your own recordings

Pretrained checkpoints are on the release page. Each script writes one row per frame and prints the contiguous mode segments:

python infer/infer_ensemble.py \
    --mel song.wav --pesto song.f0.csv --midi song.mid \
    --weights 0.5 0.1 0.4

See the README for installation, feature extraction and training.
